# Castle Vanguard 3D: Web Genesis

An immersive, high-performance 3D retro First-Person Shooter (FPS) built with **Three.js WebGL** and **Web Audio API**.

> **Note**: This project was generated using **Google Antigravity**.

## 🎮 Game Features

- **Atmospheric 3D Castle Environment**: Gothic stone walls, dynamic flickering torch lighting, iron doors, keycard lock mechanics, and secret push-walls.
- **5-Weapon Arsenal**: Combat Blade, Tactical Pistol, Storm SMG, Rocket Launcher, and Flamethrower.
- **Dynamic Audio Synthesizer**: 100% procedural Web Audio API sound effects for gunshots, explosions, footsteps, voice barks, and ambient music loop.
- **AI Enemies & Boss Fight**: Soldiers, SS Officers, Mutant Monsters, and the cybernetic **Iron Dreadnought Boss** with top-of-screen health bar.
- **Interactive Hazards & Secrets**: Explosive fuel barrels with splash damage, hidden push-walls, health/ammo pickups, and secret discovery fanfares.
- **Retro HUD & UI**: Animated BJ-style hero portrait, health/armor bars, ammo counter, minimap radar, objective tracker, pause menu, and game over / victory overlays.
- **60+ FPS Optimization**: $O(1)$ Spatial grid collision detection, 10 FPS throttled 2D HUD canvas updates, and fast `MeshLambertMaterial` lighting.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nimeshnischal/castle-vanguard-3d.git
   cd castle-vanguard-3d
   ```

2. **Serve the project using Python or any static HTTP server**:
   ```bash
   python3 -m http.server 8080
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8080` and click **ENTER THE FORTRESS**.

## 🕹️ Controls

- **WASD / Arrows**: Move / Walk
- **Mouse**: Look around / Aim
- **Left Click**: Attack / Fire Weapon
- **1 - 5**: Select Weapon
- **R**: Reload Magazine
- **Shift**: Sprint
- **Space**: Jump
- **E**: Open Iron Doors / Push Secret Walls
- **P / ESC**: Pause Menu
